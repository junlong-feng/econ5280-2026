# ECON 5280: Applied Econometrics

This is the website-only repository for the course companion. Each chapter page contains the numerical examples from the lecture notes and a short description of each example. 

## R runtimes

- Quarto Live/WebR runs Chapters 1–5 and 8–10 directly in the browser.
- Native R in GitHub Codespaces or RStudio runs Chapters 6, 7, and 11 without replacing the original `grf`, `did`, or `fixest` package code.


## Edit the site

- Chapter pages: `chapters/*.qmd`
- Navigation and course title: `_quarto.yml`
- Home page: `index.qmd`
- Appearance: `styles.css`
